# 场景编辑器

本地关卡工具，和角色编辑器同一套原则：**独立进程、不进 `npm run build`，游戏只索引保存结果。**

打开：`./dev.sh scene` 或 `./dev.sh` 后访问 `http://localhost:5175/`。

## 做什么 / 不做什么

要做：

- 周一～周五五个槽，每关一份布局 + 一份渲染氛围
- 摆墙、桌、柱、木台、绿植、饮水机、咖啡机、冰箱、懒人沙发、洗手台、咖啡吧台、文件柜、打印机、垃圾桶、置物架、白板、储物柜、会议桌、侧窗、挂壁电视、弹簧门、电梯区、玩家出生、椅子
- 陷阱：拖地未干减速；地上报纸踩上眩晕；棕色文件箱碰到眩晕并挡路；弹簧门必须贴墙并从墙上挖门洞，靠近被拍开摔倒；隐藏地板几乎看不见，踩上去把角色弹飞，触发时闪一圈白边
- 黑色遮罩从楼板挖空。游戏里不铺黑块，能看见背景/雾。矩形、圆形、三角都会改外轮廓并沿切口长出外墙；圆形和三角可转朝向。编辑器里仍显示半透明挖空，方便选中
- 选中后右侧圆盘转朝向（任意角度，四键正交吸附）。工位桌和家具都是整件转（桌面、腿、桌上物品一起）。侧窗、挂壁电视、弹簧门和电梯不转圆盘：点哪面墙就贴哪面（外墙/内墙，东西南北、斜墙、三角/圆切口都行），朝向跟着墙走
- 游戏里：椅子、绿植、垃圾桶、咖啡机、打印机可推动撞人；墙/桌/柜/沙发/会议桌等大件固定挡路；窗户和挂壁电视可从下面穿过
- 工位桌可选橡木/胡桃/深色/白桌/钢桌/长台；桌上按复杂度：单屏 → 双屏 → 杂物 → 堆满（堆满会随机铺键鼠、盆栽、杯子等）
- 家具/椅/桌上用品两套成色：亮色（白/米）和暗色（木/炭灰）。场景有默认，单件可覆盖。只换颜色，不加灯
- 墙底色只给还没上色的面。要用选择工具点某一面，右侧取色或贴图只改那一面（外墙也可以）。贴图按原比例齐高或齐宽，不拉伸。木台仍是木纹
- 绿植五档：单盆 → 双盆 → 三盆 → 多盆 → 树丛。同档每盆高低、叶色、花器也会不一样。游戏里都能冲倒
- 侧窗按天气换玻璃自发光：白光 / 晚霞 / 夜晚。窗户不加灯、不铺星星网格。挂壁电视屏幕只自发光，不加点光
- 地面可切换程序地毯/木纹/地砖，或上传图片并调重复
- 电梯贴墙挂：轿厢、对开门、墙钮、楼层屏。点哪面墙就贴哪面，朝向跟着墙，斜墙和三角/圆切口也能挂。游戏里第一次靠近门口垫变绿并开始等梯，离开后再靠近一次才开门通关
- 调雾、曝光、一层底光、墙/地颜色，可上传地面/整屋墙体贴图；单面还可再贴一张图（原比例，齐高或齐宽）
- 保存到 `public/levels/catalog.json`；贴图落到 `public/levels/textures/`
- 预览走游戏同一套 `Level` 网格和 `atmosphere`，避免编辑器里好看、进游戏对不上
- **按手机预算出图**：点光最多 6 盏，无阴影、无追光、预览关抗锯齿

不要做：

- 不进战斗 HUD，不进发布包
- 不做法线/GI/材质节点图。渲染管线仍在游戏代码里，编辑器只选参数和贴图
- 不替代角色编辑器（皮肤/发型仍是 `:5174`）
- 不再均匀铺一层看不见的顶光网格。只拧全局强度出不来「有亮有暗」

## 灯光怎么摆

场景里只剩两种光（按手机 WebGL2 能流畅跑的预算）：

- **环境光**：整屋均匀垫一层，让没灯的地方能看见轮廓。
- **地光**：半球光。头顶偏天空色、脚下偏地面反弹，暗处有体积，比死拧环境光更不容易把点光斑冲平。
- **点光**：最多 **6 盏**。点在哪，地上就有一汪亮斑。强度上限 80，半径上限 20。半径加大几乎不增加开销，灯叠在一起只会让斑更平。

追光、软阴影、每扇窗 3 盏灯、玻璃星星网格已经拿掉。窗户只改自发光颜色。

旧 catalog 若灯太多或还开着追光，加载时会自动裁到 6 盏并关掉追光。雾远小于雾近时会自动拉开，避免整屋被雾吃掉。

## 游戏怎么读

`src/game/game.ts` 启动时 `loadLevelCatalog()`，默认加载 `catalog.active` 那一关。开发预览其它天：`http://localhost:5173/?day=friday`。

旧 catalog 没有 `pointLights` 时，会套用该关种子里的成组点光。

`npm run build` 会丢掉 `levels/` 里未被 catalog 引用的贴图，并排除 `tools/scene-editor/`。

## 操作

- 左键：当前工具（选择可拖动物体；墙/桌/挖空拖出范围；电梯/侧窗/电视/弹簧门点墙放置；点光/植物/椅子点击放置）
- 右键拖：旋转；Shift 或中键拖：平移；滚轮：远近
- Delete：删除选中（外墙、玩家点、电梯区不能删，只能改）
- 「设为游戏当前关」把 `active` 写成这一天
- 「从周一带入布局」只复制几何，保留本关氛围
- 「恢复原型」用代码里的种子关覆盖该槽
