# 我要下班！ · 技术验证原型（阶段 0）

移动端竖屏 3D 逃脱生存游戏的最小技术验证：验证「群体追逐围堵 + 物理布娃娃击飞 + WebGPU 渲染」在 Web 端可行。

## 运行

```bash
./dev.sh          # 游戏 :5173 + 角色编辑器 :5174 + 场景编辑器 :5175
./dev.sh game     # 只开游戏
./dev.sh editor   # 只开角色编辑器
./dev.sh scene    # 只开场景编辑器
```

浏览器打开 `http://localhost:5173`。桌面会看到 **9:16 竖屏舞台**（左右黑边），真机竖屏铺满。手机测试：`./dev.sh game` 带 `--host`，用同一局域网访问终端打印的 Network 地址。

线上试玩（GitHub Pages）：https://funkja2413.github.io/xiaban/

同事角色编辑器是**本地资产库**：`http://localhost:5174/`。游戏角色规划在 `src/roster.ts`（现在 5 个：玩家、普通同事女/男、主管、拦截者）。编辑器按槽位保存形象到 `public/models/colleagues/catalog.json`。规划加角色后，编辑器点「刷新规划」或保存 `roster.ts` 即可跟上。发型预览库在 `tools/editor/library/`，不进发布包。

场景编辑器同样是本地工具：`http://localhost:5175/`。周一到周五各一槽，编辑墙/桌/椅子，点光最多 6 盏（手机预算，无阴影无追光）。保存到 `public/levels/catalog.json`。游戏只索引这份数据和被引用的贴图。发布包不含编辑器。开发时可用 `http://localhost:5173/?day=wednesday` 预览未设为当前关的那一天。

发布：

```bash
npm run build     # 只打游戏；catalog 未引用的同事素材（含发型库）不会进 dist
```

推到 `main` 后，GitHub Actions 会把游戏发到 Pages。仓库子路径用 `BASE_PATH=/xiaban/`；本地 `npm run build` 仍是相对路径 `./`。

若本机已有 Node 22+，也可以直接 `npm run dev` / `npm run editor`。

## 规则

基础逻辑一句话：**同事是流体，你是引力源——把人潮引开，趁路薄的时候穿过去。**

- 同事贴身读条约 2 秒成功「塞任务」则加班 +15~45 分钟；到 24:00 失败。射击击退可打断读条
- 敌人体系（每种只违反基础规则的一条）：
  - **A 普通同事**：被你吸引、成群、可被冲刺撞飞
  - **C 重量级**（深色大块头）：冲刺撞不动反被弹开硬直，守在关键门口不远追；只有高速办公椅能砸翻
  - **F 拦截者**（红色）：不追你，去你通往电梯的必经之路蹲守
- 地图为四段式迷宫（工位区→隔断迷宫→会议区三门→大厅），每段至少两条路线；绿色箭头指向电梯最优路径
- 终局：进入电梯区按下呼叫，坚守 20 秒等电梯到达，再进入电梯区即胜利

## 技术架构

- **渲染**：three.js `WebGPURenderer`（不支持 WebGPU 时自动回退 WebGL2）；60 个敌人用两个 `InstancedMesh`（身体 + 头）批量渲染，布娃娃状态切换为独立网格
- **物理**：Rapier（WASM）。敌人平时是单个锁旋转的动力学胶囊体；被强击时替换为 7 刚体 + 6 球关节的布娃娃，倒地稳定后原地爬起恢复胶囊体
- **寻路**：`src/sim/flowfield.ts` 网格流场——每 0.15s 从玩家位置 BFS 一次，所有敌人 O(1) 查表取方向；成本与敌人数量无关
- **局部避障**：空间哈希邻居分离力 + 物理碰撞，狭窄走道自动涌现排队/堵门行为
- **子弹**：运动学弹体 + 2D 线段命中检测，无物理刚体开销
- **主循环**：固定 60Hz 物理步进 + rAF 渲染，`fps / 物理耗时 / 敌人数` 实时显示在左上角

## 验证结果（桌面 Chromium / Apple Silicon）

- WebGPU 后端，120 fps（满帧），60 敌人 + 多具布娃娃时物理步进约 0.5ms
- 群体追逐、窄门堵截、冲刺撞飞、椅子保龄球、布娃娃爬起均按预期工作

```
public/levels/             游戏引用的关卡 catalog.json 与贴图
```
